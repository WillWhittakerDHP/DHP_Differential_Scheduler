# Feature 4: Calendar & Appointment Availability

**Status:** Planning  
**Description:** Build calendar component for appointment availability, time slot selection, and differential scheduling logic.

## Overview

This feature builds the calendar component and appointment availability functionality for the booking wizard. It includes time slot selection, differential scheduling calculations (where inspector and client arrive at different times), and integration into the booking wizard flow.

## Key Objectives

1. Build calendar component UI
2. Implement time slot selection logic
3. Implement differential scheduling calculations
4. Integrate into booking wizard availability step

## Phases

- **Phase 4.1**: Calendar Component UI
- **Phase 4.2**: Time Slot Selection Logic
- **Phase 4.3**: Differential Scheduling Calculations
- **Phase 4.4**: Availability Step Integration

## Differential Scheduling

Differential scheduling allows the inspector and client to arrive at different times. The inspector arrives early to perform the inspection, and the client arrives later for a presentation. The time difference varies based on property details (size, type, etc.).
